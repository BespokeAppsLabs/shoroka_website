# Shoroka Creations Color Theme

## Brand Identity
The Shoroka Creations brand is defined by a luxurious and professional combination of **Royal Blue-Purple** and **Metallic Gold**, representing the "First Class Experience" and the richness of the soil ("Sons of the soil").

## Color Palette

### Primary Colors

#### Shoroka Royal Purple
Used for the logo icon, geometric branding elements, and primary headers. Represents depth, royalty, and stability.
- **Hex:** `#33206E`
- **Estimated RGB:** `51, 32, 110`
- **Use Case:** Backgrounds for white text, logo elements, geometric shapes.

#### Shoroka Gold
Used for the "SHOROKA" text, logo gradients, and borders. Represents wealth, value, and the "seed" aspect of the motto.
- **Hex:** `#C7A963` (Gradient range: `#E6C200` to `#A88930`)
- **Estimated RGB:** `199, 169, 99`
- **Use Case:** Headings, accents, borders, gradients.

### Secondary Colors

#### Industrial White
- **Hex:** `#FFFFFF`
- **Use Case:** Main content backgrounds, text on Purple backgrounds.

#### Construction Slate
- **Hex:** `#1C1C1E`
- **Use Case:** Body text, industrial machinery contexts.

## Design Application
- **Gradients:** The gold is often used as a gradient rather than a flat color to give a metallic effect.
- **Shapes:** The brand uses rounded squares (rhombus shapes) in purple with white/gold outlines.
- **Typography:** Serif fonts for headers (elegant) combined with clean sans-serif for body text.

## CSS Variables
```css
:root {
  --color-shoroka-purple: #33206E;
  --color-shoroka-gold: #C7A963;
  --color-shoroka-white: #FFFFFF;
  --color-shoroka-slate: #1C1C1E;
  
  --gradient-shoroka-gold: linear-gradient(135deg, #E6C200 0%, #A88930 100%);
}
```
